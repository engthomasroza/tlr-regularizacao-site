# TLR Regularização

Landing page (página única, navegação por âncoras) da TLR Engenharia e Regularização Ltda.

Stack: Vite + React + TypeScript + Tailwind CSS v4 + lucide-react + framer-motion.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

Gera a pasta `dist/`, pronta para deploy em Vercel ou Netlify.
